# Merciport Administrator User Manual
**Version:** 1.0 | **Role:** Platform Operator / Admin

## 1. The Command Centre
### Platform Overview
1. Log in to the **Admin Dashboard**.
2. View the **Global Carbon Offset** metric to see the total impact of the entire Merciport ecosystem.
3. Monitor the total number of verified suppliers currently active.

## 2. Supplier Verification
### Vetting New Partners
1. Navigate to the **Pending Verifications** page.
2. Review the application details of the supplier.
3. Once vetted, click the **Verify** button.
4. The supplier is now live and discoverable by customers in the mobile app.

## 3. System Maintenance
- **User Management:** Manage user roles and permissions to ensure secure access to the platform.
- **Impact Auditing:** Review the `CarbonLogs` to ensure the accuracy of environmental reporting.
